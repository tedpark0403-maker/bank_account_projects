# 은행 계좌 관리 콘솔 프로젝트 (Python / Java / C#)

각 언어별 특성과 기본 문법(객체지향 설계, 콘솔 입출력, 메뉴 루프, 예외 처리)을 비교해볼 수 있는 기초 프로젝트 패키지입니다.

## 폴더 구조
- `python_bank/`: 파이썬 단일 스크립트 기반 프로젝트 (`bank_app.py`)
- `java_bank/`: 자바 클래스 분리 구조 (`Account.java`, `Main.java`)
- `csharp_bank/`: 최신 .NET 기반 C# 프로젝트 (`Account.cs`, `Program.cs`, `BankApp.csproj`)

## 각 언어별 실행 명령어
- `Python`: python bank_app.py
- `Java`: javac Account.java Main.java 후 java Main
- `C#`: dotnet run (또는 Visual Studio에서 솔루션/프로젝트 열기)
