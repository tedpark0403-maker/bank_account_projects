# C++ 은행 계좌 관리 프로젝트

## 컴파일 및 실행
```bash
g++ -std=c++17 -o bank_app main.cpp Account.cpp
./bank_app
```


.cpp와 .h는 C++ 소스 코드를 두 종류의 파일로 나눌 때 쓰는 확장자예요.

.h (헤더 파일) — "선언부". 클래스나 함수가 어떤 모양인지(이름, 매개변수, 반환 타입)만 적어둔 파일입니다. 예를 들어 Account.h에는 Account 클래스에 deposit, withdraw 같은 메서드가 있다는 것만 선언되어 있고, 실제로 어떻게 동작하는지는 없습니다. 다른 파일에서 이 클래스를 쓰려면 #include "Account.h"로 불러옵니다.

.cpp (소스 파일) — "구현부". 헤더에서 선언한 함수/메서드가 실제로 어떻게 동작하는지 코드를 작성하는 파일입니다. Account.cpp에 deposit, withdraw의 실제 로직이 들어있고, main.cpp에는 프로그램의 진입점(main 함수)이 들어있습니다.

비유하자면 .h는 "메뉴판"(무엇을 제공하는지), .cpp는 "주방"(실제로 어떻게 만드는지)에 가깝습니다.

Java의 경우 .java 파일 하나에 선언과 구현이 함께 있는 것과 달리, C++/C는 관습적으로 이걸 나눕니다. 이렇게 나누면:

다른 .cpp 파일들이 헤더만 #include해서 클래스를 사용할 수 있고,
구현(Account.cpp)을 수정해도 그걸 쓰는 다른 파일들을 매번 다시 컴파일할 필요가 줄어듭니다(컴파일 속도 이점).
