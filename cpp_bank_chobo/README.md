# C++ 은행 계좌 관리 프로젝트 (초보용 버전)

cpp_bank 프로젝트를 완전 초보자도 이해할 수 있게 다시 만든 버전입니다.

## cpp_bank와 달라진 점
- .h(헤더) 파일이 없습니다. 코드가 main.cpp 하나에 다 들어있습니다.
- class 대신 struct를 사용해서 private/public을 신경 쓸 필요가 없습니다.
- friend 함수 문법을 쓰지 않고, 그냥 평범한 함수로 이체 기능을 구현했습니다.
- 기능(입금/출금/잔액 조회/이체/종료)은 원래 버전과 동일합니다.

## 컴파일 및 실행
```bash
g++ -std=c++17 -o bank_app main.cpp
./bank_app
```
